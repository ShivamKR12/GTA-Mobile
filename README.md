# GTA-Mobile

An open-world 3D mobile game prototype developed in Godot 4.4.

## Features
- Third-person player controller with weapons and animations
- Driveable vehicle system with dynamic camera
- Procedural/modular city layout and day-night lighting cycle
- Options menu (dynamic shadows, sky shader, master volume)
- Automated Android APK builds via GitHub Actions

## Requirements
- Godot 4.4.1-stable
- Android device (ARM64) for mobile deployment
